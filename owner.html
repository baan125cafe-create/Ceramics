Google Sheets Connection

Paste the Web App URL from Google Apps Script. Both owner.html and staff.html must use the same URL.

Setup Guide

1. Go to sheets.google.com → create new sheet 2. Click Extensions → Apps Script 3. Delete existing code, paste gas_code.js 4. Click Deploy → New deployment 5. Type: Web App Execute as: Me Who has access: Anyone 6. Authorize → copy the URL 7. Paste URL above → Save
